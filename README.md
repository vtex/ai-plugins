# ai-plugins

Marketplace for **VTEX AI plugins** — Claude and ChatGPT (Codex) packages that help the ecosystem work with the VTEX platform.

Plugins are listed in the Claude and ChatGPT marketplaces at the repo root (`.claude-plugin/` and `.agents/plugins/`). Each plugin has its own package directories and docs.

## Available plugins

| Plugin | Platforms | Description |
| ------ | --------- | ----------- |
| **[VTEX Solution Architect Agent](./docs/vtex-solution-architect-agent/si-onboarding.md)** | Claude, ChatGPT (Codex) | Architecture guidance, platform expertise, and read-only account inspection for System Integrators |

## Platforms

- **Claude** (Cowork / Claude Code) — `claude-plugin/`
- **ChatGPT** (Codex) — `codex-plugin/`
