# Query shaping for VTEX Architect

Build broad semantic queries that include:

- VTEX domain: Checkout, OMS, Catalog, Pricing, Promotions, Logistics, Payments, Marketplace, Master Data, IO apps.
- Decision alternatives: marketplace vs franchise, native vs custom, single account vs multi-account, app vs external service.
- Constraints: PCI, LGPD, order lifecycle, account boundaries, SLA, scalability, operational ownership.

Example:

`VTEX marketplace vs franchise accounts multi-store checkout OMS catalog pricing governance constraints`
