# Query shaping for VTEX Inspector

Build diagnostic queries that include:

- Symptom or exact error message.
- Affected VTEX domain: Checkout, OMS, Payments, Catalog, Pricing, Promotions, Logistics, Marketplace, IO, Master Data.
- Failing object: orderForm, order, transaction, SKU, product, promotion, route, webhook, app, workspace.
- Observed behavior vs expected behavior.

Example:

`VTEX payment transaction approved orderForm paymentData not updated checkout callback failure troubleshooting`
