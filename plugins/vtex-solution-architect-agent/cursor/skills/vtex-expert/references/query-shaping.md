# Query shaping for VTEX Expert

Build narrow technical queries that include:

- Endpoint, API, entity, app, object, or payload names.
- The action: create, update, configure, authorize, cancel, settle, index, install, deploy.
- The VTEX domain: Checkout, OMS, Payments, Catalog, Pricing, Promotions, Logistics, Marketplace, IO, Master Data.

Example:

`VTEX checkout orderForm paymentData update API payload transaction authorization connector`
